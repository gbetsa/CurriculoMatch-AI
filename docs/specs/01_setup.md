# Bloco 1: Configuração do Ambiente e Estrutura Base

## Descrição
Configuração inicial do projeto, ambiente virtual e estrutura de pastas essenciais.

## Critérios de Aceite
- [ ] Ambiente virtual (venv) criado.
- [ ] Arquivo `requirements.txt` criado contendo: `langgraph`, `langchain`, `langchain-groq`, `python-dotenv`, `pydantic`, `pymupdf`, `pathlib`.
- [ ] Arquivos `.env.example` e estrutura para `.env` criados com chaves `LLM_PROVIDER` e `GROQ_API_KEY`.
- [ ] Estrutura de diretórios criada: `input/`, `output/`, `graph/`, `tools/`, `prompts/`.
