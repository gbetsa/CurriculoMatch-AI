# Bloco 4: Criação dos Prompts

## Descrição
Isolamento e criação dos prompts sistêmicos que serão enviados à LLM (no nosso caso, Groq) garantindo direcionamento claro.

## Critérios de Aceite
- [ ] `prompts/extract_prompt.py` implementado instruindo rigorosamente a extração de dados brutos para formato JSON/Pydantic.
- [ ] `prompts/analyze_prompt.py` implementado para cruzar as informações, calcular o score de aderência e gerar resenhas, pontos fortes e fracos.
